# Predictive-Modelling
A machine learning pipeline using Python and Scikit-Learn to predict property values through regression, PCA, and clustering.

# Predictive Market Modeling & Consumer Insight Analysis
**BSc Computing Specialisation Project**

## Project Overview
This project demonstrates a full machine learning pipeline for predicting market values and segmenting data trends. While the core model analyses real estate metrics, the framework is built for scalability—making it directly applicable to retail demand forecasting and product performance analysis.

## Technical Stack
* **Language:** Python 3.x
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, PIL (Pillow)
* **Techniques:** Linear Regression, K-Nearest Neighbors (KNN), SVM, PCA, K-Means Clustering, t-SNE

## Repository Structure
* `/data`: Contains raw datasets (`Property.csv`) and smart-asset archives (`Employees.zip`).
* `/notebooks`: Core analysis and model training logic.
* `requirements.txt`: Environment dependencies for reproducibility.

## Key Achievements
1. **Data Engineering:** Managed missing value imputation and categorical encoding for a multi-variable dataset.
2. **Dimensionality Reduction:** Utilized **PCA** to simplify complex feature sets while maintaining 95%+ variance, optimizing model training speed.
3. **Clustering:** Implemented **K-Means** to identify hidden patterns in consumer/property ratings, providing deeper segmentation insights.
4. **Predictive Accuracy:** Achieved high-confidence scoring using a tuned **Random Forest/Regression** approach.
